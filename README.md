# Random Cursor

Windows 鼠标指针主题自动轮换小工具。把光标主题放进文件夹，它会每隔一段时间换一套。

用 AutoHotkey v1 编写，单文件，不需要安装。

## 功能

- 定时随机轮换。一轮之内每套主题各出现一次，不会连续重复；也可以改成按顺序轮换
- 读取主题自带的 `install.inf` 识别每一种指针；没有 inf 的主题按文件名识别（支持常见的英文和中文命名）
- 支持动态光标 `.ani` 和静态光标 `.cur`
- 只提供安装程序的主题，可以装好后一键导入成普通主题
- 首次运行时自动备份系统原本的光标，随时可以一键恢复
- 托盘菜单：立即切换、暂停、恢复原始光标、开机启动、修改配置

## 使用方法

1. 从 [Releases](../../releases) 下载 `RandomCursor.exe`，放进一个单独的文件夹
2. 运行一次，会自动生成 `themes` 文件夹和 `config.ini`
3. 把光标主题文件夹放进 `themes`，一套主题一个文件夹
4. 十秒左右会自动开始轮换，并弹出提示显示当前主题名，说明程序已成功运行

```
RandomCursor/
├── RandomCursor.exe
├── config.ini
└── themes/
    ├── 主题A/
    │   ├── install.inf
    │   ├── normal.ani
    │   └── ...
    └── 主题B/
        └── ...
```

程序运行时会每隔 10 秒检查一次 `themes` 文件夹，新增或删除主题不需要重启。

## 托盘菜单

右键任务栏右下角的绿色 H 图标：

| 菜单项 | 作用 |
|---|---|
| 立即切换主题 | 马上换下一套（双击图标也可以） |
| 暂停自动轮换 | 打勾时暂停，再点一次恢复 |
| 打开 themes 文件夹 | 放主题的地方 |
| 导入当前系统光标为主题 | 把系统正在用的光标复制成一套主题（见下文） |
| 打开配置文件 | 用记事本打开 `config.ini` |
| 重新加载配置 | 修改配置后点这个生效，不用重启 |
| 恢复系统原始光标 | 还原成第一次运行前的光标，并暂停轮换 |
| 开机启动 | 打勾表示已开启 |
| 退出程序 | 退出（光标会停留在当前主题） |

## 配置

`config.ini`：

```ini
[Settings]
; 轮换间隔（毫秒），默认 600000 = 10 分钟，最小 10000
Interval=600000
; random = 随机，sequence = 按顺序
Order=random
; 1 = 每次切换都提示，0 = 只在启动时提示
NotifyEachSwitch=0
```

## 主题兼容性

- **带 `install.inf` 的主题**：按 inf 里写的对应关系应用，兼容性最好
- **没有 inf 的主题**：按文件名猜每个文件对应哪种指针，例如 `normal`/`正常` → 正常选择，`link`/`链接` → 链接选择
- 主题里没有提供的指针会显示为 Windows 默认样式
- 主题文件夹里多出来的说明文件、预览图不影响使用

### 只有安装程序（exe）的主题

有些主题只提供安装程序，光标文件打包在程序里面，直接放进 `themes` 无法识别。这种可以这样导入：

1. 右键托盘图标，先把「暂停自动轮换」打勾
2. 运行主题自带的安装程序，装好并应用这套光标
3. 右键托盘图标，选「导入当前系统光标为主题」，起个名字确定
4. `themes` 里会多出一个文件夹，里面是复制出来的光标文件和自动生成的 `install.inf`，之后就和普通主题一样参与轮换
5. 取消暂停

一个安装程序里有多套样式的话，每应用一套就导入一次。

如果某套主题显示不完整，可以打开 `cursor_log.txt`，里面会记录每次切换识别到了几种指针、缺了哪些。

## 从 5.1 升级

5.1 每次启动都会重新备份，所以旧的 `backup.ini` 里存的可能已经是某套主题，不是系统原本的光标。升级步骤：

1. 退出旧版程序
2. 打开「设置 → 蓝牙和其他设备 → 鼠标 → 其他鼠标设置 → 指针」，把方案改回「Windows 默认」或你原本用的方案
3. 删除旧的 `backup.ini`
4. 运行新版

`config.ini` 可以继续用，新增的配置项不写时用默认值。

## 从源码运行 / 自己编译

- 需要 [AutoHotkey](https://www.autohotkey.com/) **v1.1.33 或更高的 v1 版本**，不支持 v2
- 源码文件需保存为 **UTF-8 with BOM**，否则中文菜单会乱码
- 编译：用 AutoHotkey 自带的 Ahk2Exe，选择 `RandomCursor.ahk` 生成 exe

AutoHotkey 编译的 exe 偶尔会被安全软件误报，这是 AHK 程序的常见情况。不放心的话可以直接运行源码。

## 运行时生成的文件

| 文件 | 说明 |
|---|---|
| `config.ini` | 配置 |
| `backup.ini` | 系统原始光标的备份，删除后下次启动会重新备份当前光标 |
| `cursor_log.txt` | 运行日志，超过 512KB 自动归档为 `cursor_log.old.txt` |
